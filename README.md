# 🎉 Events Application 

A full-stack **Event Application** built using the **MERN Stack** that allows users to explore, register, and manage event participation efficiently — even as event data grows continuously.

## 🚀 Tech Stack

This project is built using the **MERN Stack**:

* **Frontend:** React.js
* **Backend:** Node.js (Express.js)
* **Database:** MongoDB (Preferred) / SQLite


---

## 📌 Project Overview

The platform enables users to:

* Browse available events
* View event details
* Register and cancel event participation
* Search and filter events dynamically
* Manage their registered events through a personalized dashboard

The system is designed to efficiently handle continuously expanding event collections while maintaining a smooth user experience.

---

## 🔐 Authentication Features

* User Registration
* User Login
* Secure authentication using JWT
* Protected routes for authenticated users
* Session-based access control
